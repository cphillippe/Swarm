# Swarm
Particle scale-up game prototype: start in 3D as a subatomic swarm, grow through atoms and dust, and at mass 1500 gravity switches the game to 2D.

## How to play
- Steer: mouse, WASD, or drag (touch)
- Dash: Space or tap
- Red swarms eat you; green ones are edible
- Reach mass 1500 to trigger gravity and the 2D surface stage
